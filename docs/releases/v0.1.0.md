# Smart Clipboard 0.1.0 — Preview

A native macOS menu bar app that turns selected screen regions or windows into useful clipboard content.

## Download and install

**Apple Silicon (M1 or newer), macOS 14+.** Download `Smart-Clipboard-0.1.0-macOS-arm64.dmg`, open it, drag **Smart Clipboard** onto **Applications**, then launch the installed app. A ZIP alternative and `SHA256SUMS.txt` are included below. No build tools are needed to run the downloaded app.

**This preview is ad-hoc signed and is not Apple-notarized.** After attempting to launch it, macOS may require **System Settings → Privacy & Security → Open Anyway**. Only make that exception if you trust this download; see [Apple's guidance](https://support.apple.com/en-us/102445). Managed Macs may disallow it.

## Included

- Rectangle and window capture using the native macOS selector; Space switches modes.
- Image copy/export and offline Apple Vision text extraction.
- AI descriptions, plain text, Markdown, HTML, SVG, JSON, YAML, and automatic format selection.
- Optional translation or formatting directions, editable results, copy and file export.
- OpenAI API keys stored in Keychain, or ChatGPT access through the official Codex CLI.
- Configurable global shortcuts, launch-at-login setting, native light/dark appearance, and a green capture-frame app icon.

## First run

Grant Screen Recording permission when prompted, then configure **Settings → Connection**. ChatGPT mode requires a separately installed recent Codex CLI and a plan with Codex access. API billing is separate. Image copying and local OCR work without an account. Captures are uploaded only after choosing **Convert with AI**.

Default shortcuts: **Option–Shift–Command–3** for a region; **Option–Shift–Command–4** for a window. Enable launch at login after moving the app to Applications.

## Validation and preview limitations

All 16 automated tests passed, including response validation, process cancellation/timeouts, and OCR on a generated fixture. The release app's signature and archive contents were checked. Live screen capture, multi-display behavior, login-item approval and actual API/ChatGPT conversions still need hands-on acceptance testing with configured accounts. AI reconstruction may be imperfect. Intel binaries, automatic updates, and Apple notarization are not included in this preview.
