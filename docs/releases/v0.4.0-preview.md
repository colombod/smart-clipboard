# Smart Clipboard 0.4.0 preview — unpublished draft

This is a development candidate, not a published release or a claim of completed acceptance. The public download remains 0.3.1. The candidate adds Anthropic, Google Gemini, Perplexity and local oMLX connections alongside OpenAI and ChatGPT/Codex, plus About/help and signed-update support. See the [user guide](../USER-GUIDE.md) for setup and the [provider status](../PROVIDERS.md) for verification scope.

## Local model guidance

Use an image-capable model with a compatible oMLX server. The unmodified official **oMLX 0.7.0.dev2 prerelease** contains the structured-output fix missing from tested 0.6.4. A larger model alone does not repair that server bug.

- **[mlx-community/Qwen3-VL-8B-Instruct-4bit](https://huggingface.co/mlx-community/Qwen3-VL-8B-Instruct-4bit):** about 5.78 GB in the publisher's file listing. Synthetic text/table extraction worked, but Description invented observations and SVG reconstruction distorted the source geometry. It has not passed all-format quality acceptance.
- **[mlx-community/Qwen3-VL-32B-Instruct-4bit](https://huggingface.co/mlx-community/Qwen3-VL-32B-Instruct-4bit):** verified complete download of 19.64 GB / 18.29 GiB. Testing preserved the expected values, but Description invented alignment details and SVG failed canvas/grid checks. It is not an accepted fix for the smaller model's quality limitations.

Allow 16 GB or more unified memory for 8B, or 48 GB or more for 32B, as **planning estimates only**. Running memory depends on image size, context and other apps; lower-memory Macs have not been tested. The measured test environment had 128 GiB. The [local setup and model guide](../USER-GUIDE.md#set-up-local-image-processing-with-omlx) records exact IDs, size sources and connection steps.

## Acceptance still open

The packaged 8B run passed its then-current structural/value checks, but manual review failed Description and SVG. Twelve bounded follow-up probes across tables, prose and diagrams did not establish a reliable prompt fix. The tests now reject the known invented-correction and aspect-ratio failures; this does not prove complete visual fidelity. See [the preserved synthetic evidence](../testing/OMLX.md).

The 32B app-path run failed the SVG aspect-ratio assertion, and manual review also found invented Description details. Six bounded prompt probes with trusted source dimensions fixed SVG canvases but retained incorrect table structure and unsupported Description claims. No experimental prompt was adopted into production.

Description/SVG quality and the remaining [native workflow/release gates](../UAT.md) must be resolved before public-release acceptance. Download integrity, a successful connection test, and imported-image conversion do not establish native shortcut → capture → focus recovery → paste behavior. No new release is published by these notes.
