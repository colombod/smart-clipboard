# Smart Clipboard 0.4.0 preview — build 12

Smart Clipboard now speaks your language—and can translate the text you capture. Keep using your capture shortcut, wait for the ready status, then paste into your current app. Settings and the editor still open only when you ask.

## What is new

- **An interface in five languages.** Menus, settings, notifications and accessibility labels support English, Italian, Spanish, French and German. The app follows your Mac’s preferred supported language, with English as the fallback. Restart Smart Clipboard after changing its language in macOS.
- **Keep the source language by default.** A new installation preserves the language or languages detected in an image, even when your Mac uses another language. Changing the interface language does not translate your captures.
- **Automatic translation when you want it.** In **Settings → General → Languages → Capture output**, choose **System language** or a specific language. Your next AI capture is translated through your selected connection, including local oMLX, and copied automatically. Choose **Keep source language** to turn translation off.
- **More languages from an earlier capture.** Open **History**, select a capture, choose an **Output language**, then **Convert with AI**. Each format and language keeps its own saved result. Translating a Spanish capture into French keeps the earlier Spanish and English versions available under **Saved formats**.
- **Existing directions are preserved on upgrade.** If you already use saved directions, **Use saved directions** keeps their previous behavior. Choosing a language adopts the new control; that choice takes priority over conflicting translation directions. Older history entries with directions retain their existing behavior too.

**Pass through (image)** still copies the original screenshot without extraction or an AI request. **Extract text on device** keeps the source language and does not translate. History never copies a result merely because you open it: use **Copy**, or enable **Copy after manual conversion**.

## Try it

1. Install the DMG in **Applications**, then open Smart Clipboard. Look for **Clip** in the menu bar.
2. Keep your existing connection, or choose one in **Settings → Connection** and run **Test image processing**.
3. Choose a preferred format and, if desired, a translation language in **Settings → General**.
4. Use your capture shortcut, wait for **Clip ✓** or the ready notification, and paste with **⌘V**.

Your saved shortcuts, connection, preferences and history are preserved. The default shortcuts are **⌥⇧⌘3** for an area and **⌥⇧⌘4** for a window; existing custom shortcuts take precedence. To receive preview updates, select **About → Releases → Stable and preview releases**, then check for updates.

## Using local AI

For text, tables and structured extraction, **Qwen3-VL-8B-Instruct-4bit** remains the smaller tested local option. A synthetic Spanish screenshot was successfully preserved in Spanish and translated into English and French using this model with the existing oMLX server. That is a small plain-text test, not a guarantee for every language, image or model.

The larger 32B model did not fix the existing Description and SVG accuracy problems. Consult the [local setup and model guide](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/USER-GUIDE.md#set-up-local-image-processing-with-omlx) for the exact download IDs, estimated memory needs and tested oMLX server version before installing a model.

## Verification and preview limitations

Automated checks cover complete translation catalogs and placeholders, source-language preservation, explicit and system targets, settings/history migration, saved language variants, image pass-through and source-only OCR. Windowless light/dark snapshots cover settings, the capture editor and history across all five interface languages. The synthetic oMLX translation test also checked that older language variants remained saved and manual conversion did not copy when automatic copying was disabled. See the [language test evidence](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/testing/LANGUAGES.md).

- **Translation quality depends on the model and source image.** Review the result. Code, identifiers, numbers and structured syntax are requested to stay intact, but AI can make mistakes. Source-language descriptions use English when the image contains no readable text; select a target language for a different result.
- **Description and SVG remain experimental with the tested local models.** They can invent details or distort layouts. [Local model evidence](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/testing/OMLX.md).
- **Cloud connections are not all live-verified.** Model availability, account access and real capture workflows still need validation for each service. [Provider status](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/PROVIDERS.md).
- **Full accessibility acceptance remains incomplete.** Translated control labels do not establish complete VoiceOver support, pointer-free selection, text enlargement or alternative-input support. [Accessibility status](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/ACCESSIBILITY.md).
- **macOS controls notification delivery.** Focus and screen-sharing privacy settings can hide banners or silence sounds. The Clip menu continues to show status. Screen Recording approval may need refreshing after replacing an old development build. [Troubleshooting](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/USER-GUIDE.md#if-capture-does-not-work).

This remains an opt-in preview. [Acceptance criteria](https://github.com/colombod/smart-clipboard/blob/v0.4.0-preview.12/docs/UAT.md) distinguish automated and synthetic evidence from actual installed-app checks.
