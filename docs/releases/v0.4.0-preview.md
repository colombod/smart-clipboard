# Smart Clipboard 0.4.0 preview — build 15

Clearer capture shortcuts and illustrated help in five languages.

## New capture defaults

- **Region:** **⌃⌘R** — hold **Control + Command**, then press **R**.
- **Window:** **⌃⌘W** — hold **Control + Command**, then press **W**.

These replace the shifted-number defaults for fresh installations and settings without a saved binding. **Your saved shortcuts stay unchanged**, including custom keys and combinations saved by an older version. See **Settings → Shortcuts** to view or record your own choices. **Find available shortcuts** now uses matching letter keys and labels when a combination is already registered.

New letter defaults are resolved from the current Latin keyboard layout when the app starts. Saved shortcuts keep their existing physical bindings. If you change keyboard layouts while the app is open, reopen it or record your preferred combination in Shortcuts.

The shortcut handler registers physical key codes and modifier flags; it does not match the character typed by Shift. The new defaults remove the shifted-number instructions that caused confusion. A default can still conflict with another app or an enabled macOS shortcut; the app reports registration problems rather than silently disabling the other capture action.

## Illustrated help

The [getting-started page](https://colombod.github.io/smart-clipboard/) now uses real app-view screenshots with short captions. The [user guide](https://colombod.github.io/smart-clipboard/guide.html) shows preferred output, oMLX setup, offline SVG tracing, saved formats and reuse of previous captures.

Use the page’s language switcher for **English, Spanish, Italian, French or German**. Screenshots show the English interface with sample data. The app itself already supports these five interface languages; this release adds translated help pages.

## Still included

Local SVG tracing works without AI, an API key or a model. Choose **General → SVG → Trace on device**, then Photo, Logo or Line drawing and Balanced/Detailed. AI extraction supports your configured connection, including local oMLX. Captures keep the source language unless you select translation; History retains separate format and language versions.

Configure once, close Settings, capture, wait for **Clip ✓**, then paste. The update preserves your provider, history and preferences.

## Preview status

Automated shortcut checks cover new defaults, saved custom/older bindings, conflict handling and action routing. Documentation images are rendered from actual app views with isolated sample data; they are not evidence of a live capture. Repeated native capture, complete provider coverage and full accessibility acceptance were not rerun for this update.

The [build 14 notes](https://github.com/colombod/smart-clipboard/releases/tag/v0.4.0-preview.14) record earlier installed-app, tracing, export, translation and restart checks. Those observations remain scoped to their tested builds. Known limitations remain: AI can invent details, tracing keeps backgrounds and outlines text, semantic chart reconstruction is not included, and macOS can suppress notifications during Focus or screen sharing.
