# Smart Clipboard 0.2.0 — Capture History Preview

## What's new

- **Pick it for me** is an explicit output choice and configurable default. AI selects the target format from the original source, and the result displays the chosen format.
- **Persistent local history** retains the last 50 captured/imported images by default, along with their latest result for each output format.
- **Reconvert previous clips:** open History from the sidebar or menu bar, reopen a clip, choose another format and convert the original image again. Saved formats retrieves an existing result without another AI call.
- **Configurable retention:** Settings → History accepts 0–500 clips. Apply a lower limit to remove oldest entries; zero clears and disables history. Disk usage is displayed.
- **Cleanup controls:** delete individual entries or clear all history. Clearing also closes the active clip so it cannot be saved back accidentally.

## Storage change

This version saves captures and conversion results across app restarts in `~/Library/Application Support/Smart Clipboard/History/`. Access is restricted to the current macOS user; the app does not separately encrypt history. You can disable saving with a limit of zero. Exported files and the system clipboard are unaffected by history deletion. The app only stores its own captures/imports and does not monitor other apps' clipboard activity. No history is uploaded until you explicitly convert a selected capture with AI.

## Download and update

Apple Silicon (M1 or newer), macOS 14+. Quit the previous app, open the DMG, and drag Smart Clipboard to Applications to replace it. A ZIP alternative and SHA-256 checksums are included. The app remains a menu bar utility.

This preview is **ad-hoc signed and not Apple-notarized**. If macOS blocks opening it, follow [Apple's guidance](https://support.apple.com/en-us/102445) and use Privacy & Security → Open Anyway only if you trust the download. Managed Macs may prohibit this exception.

## Validation

All 31 automated tests passed. Coverage includes saved images/results surviving restart, file removal on eviction and clearing, disabled history, corrupted-index handling, cached formats, and an end-to-end local OCR conversion of a reopened original. Release archives and signatures are verified before upload. Live OpenAI calls and interactive screen-capture/GUI acceptance remain outside this automated validation.
