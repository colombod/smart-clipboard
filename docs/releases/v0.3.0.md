# Smart Clipboard 0.3.0 preview

Choose **Settings → General → Preferred format** once, then capture and paste. Captures always follow your saved preference: screenshots and imported images are converted using your configured AI connection and copied to the clipboard. Auto detect chooses the format from the source; Pass through (image) copies the PNG locally. An optional Default direction applies to each new capture.

The menu bar shows progress and a checkmark when the result is ready. App windows open only when explicitly requested, never on startup, capture completion, or error. The unintended blank Settings window has been removed by using an AppKit application lifecycle. History keeps originals for producing another format later. Failed or cancelled conversions preserve the existing clipboard.

Settings no longer reads the API key on opening, preventing a Keychain prompt from freezing its UI. Background key reads do not prompt; authorize an existing key explicitly in Connection settings after an update if needed.

Capture now requests permission directly and continues when access is granted. Denial and screenshot command failures are reported instead of opening Settings unexpectedly or silently treating errors as cancellation.

Validation: 49 automated tests, including preferred-format region/window dispatch, isolated pasteboard assertions, failure/cancellation, history and OCR. Live pass-through import → automatic clipboard copy → image paste in TextEdit is verified for this build. Region capture → manual AI conversion → text paste was verified on the preceding candidate. Automatic AI conversion in this installed build still awaits renewed Keychain authorization; multi-display/window selection needs broader acceptance testing.

This Apple Silicon preview requires macOS 14+. It is ad-hoc signed, not notarized. Updates can invalidate an existing Screen Recording grant; see INSTALL.txt for the targeted permission reset and reapproval procedure.
