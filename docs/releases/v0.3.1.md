# Smart Clipboard 0.3.1 signed preview

This release moves the public download from ad-hoc signing to **Developer ID Application signing and Apple notarization**. The app and DMG include notarization tickets for offline verification. The release workflow verifies the signing identity, hardened runtime, timestamp, Apple acceptance, stapled tickets, Gatekeeper assessment and final checksums before publishing.

The capture workflow is unchanged: configure your preferred format once, use the global shortcut, select a region or window, and paste when the menu bar indicates completion. Auto detect uses the configured AI connection; Pass through copies the screenshot without extraction. No app window opens automatically on startup, capture completion or error.

## Updating from 0.3.0 or earlier

Quit Smart Clipboard before replacing the app in Applications. Because earlier previews were ad-hoc signed, macOS may request Screen Recording approval again. If your saved API key needs renewed access, open Settings → Connection → Authorize saved key. Your history and preferences remain in their existing locations.

Signing preserves a consistent identity for future updates. Screen Recording and Keychain authorization remain separate macOS privacy controls; notarization does not grant those permissions.
